# Contributing to PersonalAI Dashboard

Thank you for your interest!

This project is a gift to the world — built for privacy, cost efficiency, and user control.

## Welcome Contributions

We especially value:
- Improvements to Model Message Bus or Vector Lake
- Token efficiency optimizations
- Privacy and security enhancements
- Beginner-friendly UX improvements
- Documentation updates

## How to Contribute

1. Fork the repo
2. Create a feature branch
3. Make changes and test locally
4. Submit a Pull Request with clear description
